Nova is a unified AI personal assistant designed to help users manage both productivity and conversations in one place. It combines a modern chatbot experience with practical tools like task tracking, notes, schedules, study planning, and a Pomodoro focus timer. Users can chat naturally for ideas, explanations, drafting, planning, and quick support, while also organizing daily work in the same dashboard.

The interface is built for simplicity and speed, with a clean sidebar, quick prompts, and provider-based AI settings. It supports multiple AI backends, making it flexible for different users and API setups. Whether someone needs help writing, studying, planning tasks, or staying focused, Nova brings those tools together in a single streamlined assistant experience.

This project works as a lightweight personal productivity + AI app, ideal for learning, daily management, and experimentation without needing a full platform setup.
